FileEngine previews PDFs right in the browser and lets you **mark them up** —
highlight, draw, add notes — and attach the marked-up copy to a **comment**, so your
feedback points at exactly the right spot. Your markup is saved as a separate copy
next to the file: the **original document is never changed**.

## Previewing a document

Open a file's **preview** to read it full-screen. **PDFs** open directly, and **Office
documents** (Word, Excel, PowerPoint) preview through their generated PDF. The
discussion sits alongside the document, so you can read and comment in the same place.

Beneath the document you'll find **⬇ Download original** to get the source file, and
**📂 Open file location** to jump to its folder in the [Files browser](#files).

## The markup toolbar

If you have permission to change the file, a **✎ Markup** toolbar sits above the
document. Pick a tool, then work directly on the page:

- **➤ Select** — the default; move or adjust existing markup.
- **▤ Highlight** — highlight text.
- **T Text** — drop a typed note.
- **✎ Draw** — freehand ink.
- **🖼 Image** — place an image or stamp.
- **✒ Sign** — add a signature.
- **↶ Undo / ↷ Redo** — step your changes back and forward (also **Ctrl+Z** / **Ctrl+Y**).

A **● unsaved markup** indicator shows whenever you have changes that aren't attached
to a comment yet.

## Saving markup with a comment

There's **no separate save step**. Mark up the document, then **write a comment and
post it** — your marked-up copy is captured and linked to that comment automatically.
It works the same whether you're starting a **new thread** or writing a **reply**.

The copy is stored next to the file and stamped to your comment. It sits **outside the
document's version history**, so saving markup never creates a new version of the
document and never alters the original.

## Building up markup across comments

Your markup **stays on the document after you save**, so you can keep going:

- Add more markup and **post another comment** to save the updated copy — each copy
  captures everything on the page at that moment.
- Click **↺ Return to original** to clear all markup and go back to the clean
  document. If you have markup that hasn't been added to a comment yet, you'll be
  asked to confirm first.

If you try to **leave the preview** while you have markup that isn't saved to a
comment, FileEngine reminds you first so nothing is lost.

## Viewing a comment's marked-up copy

A comment that has a marked-up copy shows two links:

- **📄 View marked-up copy** opens that copy in the viewer and **highlights the
  comment** it belongs to, so the connection is obvious — the link reads **Viewing
  marked-up copy** while it's on screen. **← Back to document** returns to the live
  document.
- **⬇ Download** saves the marked-up PDF to your computer.

While viewing a saved copy you can **mark it up further** and attach the result to
another comment, building on what's already there.

## Who can mark up

Marking up and saving a copy follows the file's permissions — you need **write access**
(see [how permissions work](#acl-basics)). Anyone who can **read** the file can open
and download the marked-up copies. In every other way these behave like any
[comment](#comments): replies, mentions, reviews, and live updates all apply.
